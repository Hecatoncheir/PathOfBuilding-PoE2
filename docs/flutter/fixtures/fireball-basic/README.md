# Первый эталон: Fireball

Получен из существующего Lua-движка на исходной ревизии `4174f7fd3` через имеющийся `runtime/lua51.dll`. Скрипт эксперимента добавлен после этой ревизии. Используется новый персонаж с Fireball 20/0 без предметов и назначенных пассивных умений.

Запуск из корня: `python tools/run_headless.py tools/headless_smoke.lua`.

Сценарий перезаписывает `build.xml`, `restored.xml` и `expected.json`: это получение снимка, а не независимая проверка сохранённого эталона. Изменения этих файлов следует проверять перед коммитом.

Проверены настоящие вычисления: исходный DPS `124.83333333333`, здоровье `65`; добавление `100% increased Spell Damage` удваивает DPS до `249.66666666667`; загрузка исходного XML возвращает исходные показатели. Допуск DPS — `0.000001` для этого конкретного сценария.

Первый экспорт и экспорт после загрузки отличаются нормализацией значений по умолчанию: имя набора настроек, флаги оружия/FullDPS, качество камней, параметры timeless и пустая секция торговых весов. Поэтому сохранены оба XML. Повторная загрузка нормализованного XML должна дать точно такой же экспорт.

При старте движок сообщает о нескольких отсутствующих узлах дерева. Этот эксперимент не проверяет корректность дерева, назначение узлов, все показатели, работу Busted или мобильный runtime. Запуск всё ещё создаёт исходные UI-модули через графические заглушки; независимый API движка пока не выделен.
