# Приёмка этапа 5

Этап «Дизайн Gruvbox и адаптивная оболочка» завершён. Источник оформления — `app/prototype/`; игровые данные и расчёты предоставляет оригинальный Lua.

| Требование | Реализация и проверка |
| --- | --- |
| Токены прототипа | `design_theme.dart`: поверхности, текст, границы, поля, карточки и действия. |
| Dark, Light и системная тема | `ThemeData`, `ThemeExtension`, сохранение выбора; снимки обеих тем. |
| Контраст | Тест проверяет отношение не ниже 4.5:1 для обычного, приглушённого, акцентного текста и ошибок на поверхностях обеих тем. Светлые акценты затемнены для читаемости. |
| Общие компоненты | `workshop_components.dart`, панели, поиск, подсказки и диалоги; проверены карточка предмета, таблица и выбор на малой ширине. |
| Широкий экран | Навигация слева, редактор в центре, показатели справа; разделители поддерживают перетаскивание, стрелки и сохранение размеров. |
| Планшет и телефон | Компактная навигация, один редактор, раскрываемые показатели с обновлением после ответа Lua. |
| Размеры и крупный текст | 24 сочетания: две темы, два языка, окна 360×740, 390×844, 768×1024, 1024×768, 1440×900, 740×360; текст 150%. Перемещение карты не меняет прямоугольник рабочей области. |
| Сенсорный ввод | Основные цели от 48 логических пикселей, проверки семантики; важные действия доступны кнопками и диалогами без наведения. |
| Клавиатура | Ctrl/Cmd+K, стрелки, Enter, Escape, порядок фокуса, Ctrl/Cmd+S, отмена и повтор. Проверены переходы ко всем десяти разделам. |
| Движение | Короткие переходы камеры, подсказок и состояний; системная и пользовательская настройки уменьшения движения. Тест подтверждает мгновенный масштаб при отключённых анимациях. |
| Языки и числа | Русская и английская оболочка, изменение языка в открытом диалоге, сохранение настройки, форматирование чисел. Поиск игровых названий использует исходные тексты Lua. |

## Подтверждённые проверки

- `flutter analyze --no-pub`: замечаний нет.
- `flutter test --no-pub --timeout 60s`: 22 теста пройдены.
- Четыре эталонных изображения сравниваются без расхождений: дерево, подсказка, оболочка Dark и Light.
- `flutter build windows --release --no-pub`: создан `build/windows/x64/runner/Release/pob_workshop.exe`.
- `python app/tools/check_engine_protocol.py`: проверка протокола пройдена.
- Запрос `getWorkbench` возвращает предметы, группы умений и заметки из Lua без изменения XML сборки.

## Границы готовности

Завершена оболочка и общие элементы интерфейса. Полноценное редактирование библиотеки, предметов, умений, условий боя и группы относится к последующим этапам; доступная навигация не означает готовность каждого редактора. Сейчас некоторые разделы показывают исходные данные или явное уведомление о будущем редакторе.

Малые размеры и горизонтальная ориентация проверены в тестах Flutter. Сборки Android/iOS, испытания на физических устройствах и измерение частоты кадров ещё не выполнены. Windows-приложению пока нужны исходный репозиторий и Python; автономная поставка не готова.

Файлы вне `app/` должны оставаться идентичными исходной ревизии `bb52d6b36`. Flutter занимается отображением, вводом и настройками; игровые правила, пути и показатели остаются в Lua.
